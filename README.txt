Aryan-Ai — Icon pack
Generated with the Websifu App Icon Generator (https://websifu.co/webapps/app-icon-generator)

HOW TO USE
1. Copy the contents of this zip to the root of your website.
   (favicon.ico and manifest.json should sit at the site root,
    with the /icons folder alongside them.)
2. Paste the contents of head.html into the <head> of your pages.
3. Adjust the paths if you placed the files in a sub-folder.

FILES
  favicon.ico .............. classic favicon (16/32/48 embedded)
  icons/favicon-*.png ...... PNG favicons
  icons/apple-touch-icon*.png  iOS / iPadOS home-screen icons
  icons/icon-*.png ......... Android / PWA icons (any purpose)
  icons/maskable-*.png ..... Android adaptive (maskable) icons
  icons/mstile-*.png ....... Windows tiles
  manifest.json ............ PWA web app manifest
  manifest.webmanifest ..... same manifest, W3C spec extension
                             (link ONE of them in your <head>, not both)
  browserconfig.xml ........ Windows tile config
  head.html ................ HTML tags to paste in <head>
